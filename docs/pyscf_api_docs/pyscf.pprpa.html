Orthonormalize U-ppRPA eigenvectors. The eigenvector is normalized as Y^2 - X^2 = 1. This function will rewrite input exci and xy, after calling this function, exci and xy will be re-ordered as [hole-hole, particle-particle].

Module contents#

Particle-particle random phase approximation (ppRPA)

  • rpprpa_direct: restricted ppRPA by direct diagonalization

  • rpprpa_davidson: restricted ppRPA by the Davidson algorithm

  • upprpa_direct: unrestricted ppRPA by direct diagonalization
